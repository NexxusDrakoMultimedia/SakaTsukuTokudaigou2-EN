# Helper scripts: every `tools/re/` family in one table

`tools/re/` holds about 600 research, measurement and one-shot Python scripts (about 400 at the top level, the rest in subdirectories) plus a few Ghidra launchers.  None of them is part of the build (`tools/build_patch.py` and the modules
next to it never import from `tools/re/`), and none launches an emulator.  They are named `<prefix>_<what>.py`; the prefix says which piece of work
wrote them.  This table lists every prefix family, what it is for, who owned it and where it is documented.  Run any of them as
`python -I -X utf8 tools/re/<name>.py` from the repo root; most print their usage when started with no arguments or are described in the first docstring line.

`python -I -X utf8 tools/re/doc_prefixes.py [--all]` regenerates the family list (file counts and first docstring line of each script) so this table can be checked
against the directory; at the time of writing (2026-11-11) it finds 80-odd families (the numbers in the Prefix column are top-level file counts, counted before `doc_prefixes.py` was added).

Stages: **1** = first text pipeline, engine study and the first two Flycast playtests (2026-11-10); **2** = the playtest-findings round (money, layout, names,
art, release); **3** = the stage-3 round (club-name guard, disc capacity and verification, integration, documentation, polish).  "Study" = a read-only
expansion study (`docs/expansion/`).  A script marked *one-shot* edited the repo once (an atomic rewrite of a tool or `translation/*.jsonl`) and is kept as a record,
not for re-running: check that its precondition still holds before you try.

## Conventions

* A script that writes under `translation/` says so in its docstring and writes atomically (temp file, then replace); a script without such a line is read-only.
  `*_edit*.py`, `*_apply*.py`, `art*_run.py --write` and `*_install*.py` are the writers; all others only read the disc, `extracted/`, `build/` and RAM dumps.
* Generated output goes under `build/<prefix>/` (git-ignored).  Delete it when you are done; trial discs are 1.2 GB.
* New helper scripts take a new prefix of 2 to 4 letters and get a row here in the same change.
