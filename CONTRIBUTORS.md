## Third-party work this project builds on

* **Roboto Condensed Medium**, Copyright 2011 The Roboto Project Authors (https://github.com/googlefonts/roboto-classic), SIL Open Font License 1.1: the source of the English half-width glyphs (`LICENSES/OFL-1.1.txt`, `doc/NOTICE-fonts.md`).

## The original game

Sakatsuku Tokudaigou 2: J.League Pro Soccer Club o Tsukurou!, its text, art, music, code, and the club and competition names belong to their owners.  This is an unofficial fan translation and is not affiliated with them.
The project does not license any of it.

## How to be listed

Contributors are added by the maintainer when a contribution is merged or a report leads to a fix.  Tell us in the pull request or issue how you want to be named (a name or a handle, or nothing), and in which role: translation, art, tools, testing, bug reports, documentation.
You will not be listed with an e-mail address.  To be removed or renamed, open an issue.  See `CONTRIBUTING.md` for how to contribute.
